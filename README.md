# 合租生活管家 Flatmate Butler

在线访问：https://yahuiyahui.github.io/flatmate-butler/

帮助合租室友处理费用分摊、公共物品、清洁值日和室友公约。设计原则是**默认规则自动执行，人只处理例外**。

- 费用分摊：每类费用单独约定分法（平均、按房间面积、按在住天数、自定义比例）；出差天数自动减免；单笔可改参与人和比例
- 固定费用每月自动入账；支付账单 CSV 导入并自动识别公共开销；一句话记账
- 公共物品：补货时记一次，轮流采购，低库存提醒
- 清洁值日：轮换排班，外出成员自动跳过
- 作息公约：习惯差异对比、根据差异起草公约、全员表决、匿名提醒
- 「我的」页：我要付多少、钱花在哪、今天明天要做什么
- 已预留大模型接口（小票识别、公约起草），雏形阶段关闭

单文件 HTML，无需构建。
